BIST chart action usage rules:

- For current/live chart requests, call /chart with mode=current. This is the default 45-second visual-safe mode.
- For important current decisions where a little more waiting is acceptable, call mode=safe_current.
- For dated, historical, 3-month, daily or OHLC-focused analysis, call mode=balanced.
- Never analyze a screenshot when screenshot_url is null or chart_status indicates loading/timeboxed/no_image.
- If screenshot_url exists, use the image as the main chart source and quote_snapshots as secondary price verification.
- Public quote sources can be delayed; mention delay/limitations when relevant.
